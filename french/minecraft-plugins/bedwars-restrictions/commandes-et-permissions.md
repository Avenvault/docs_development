# Commandes et permissions

Bedwars Restrictions est conçu pour fonctionner automatiquement en arrière-plan, mais inclut quelques commandes administratives pour la gestion en direct.

| **Commande**         | **Description**                                                                                                     | **Permission** |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------- |
| `/bwr help`          | Affiche le menu d'aide administrateur.                                                                              | `bwr.admin`    |
| `/bwr reload`        | Recharge le fichier `config.yml` (coordonnées des zones) sans redémarrer le serveur.                                | `bwr.admin`    |
| `/bwr wand`          | Donne la baguette de sélection de région.                                                                           | `bwr.admin`    |
| `/bwr set base-name` | Enregistre la sélection actuelle dans la configuration et bloque le placement/la destruction de blocs dans la zone. | `bwr.admin`    |

(Remarque : Les joueurs disposant du statut d'opérateur (OP) sur le serveur héritent automatiquement de toutes les permissions)
