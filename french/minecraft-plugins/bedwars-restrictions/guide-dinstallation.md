# Guide d'installation

Lancer Bedwars Restrictions sur votre réseau est simple et rapide. Assurez-vous d'avoir votre clé de licence sous la main avant de commencer.

1. Télécharger le plugin : Téléchargez la dernière version de `BedwarsRestrictions.jar` auprès de votre fournisseur.
2. Mettre en ligne sur le serveur : Glissez-déposez le fichier `.jar` dans le dossier `/plugins/` de votre serveur.
3. Premier démarrage (Génération des fichiers) : Démarrez ou redémarrez votre serveur. Le plugin va générer un fichier `config.yml` par défaut dans `/plugins/BedwarsRestrictions/` puis se désactiver temporairement (ceci est normal).
4. Entrer la clé de licence : Ouvrez le fichier `config.yml` généré et collez votre clé de licence dans le champ `license-key`.
5. Redémarrage final : Redémarrez votre serveur !

> ⚠️ Remarque : BedwarsRestrictions ne se chargera pas sans une clé de licence valide. Le rechargement via Plugman ou `/reload` n'est pas pris en charge pour l'authentification initiale. Veuillez effectuer un redémarrage complet du serveur.
