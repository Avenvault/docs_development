# Commandes

💻 Commandes

Le bot utilise l'architecture moderne des commandes Slash de Discord pour des exécutions propres et discrètes.

`/ticketpanel`

* Permission : Administrateur / Propriétaire uniquement
* Description : Déploie le menu déroulant interactif dans le salon où la commande est exécutée. Les utilisateurs interagissent avec ce panneau pour ouvrir leurs tickets en fonction des catégories définies dans votre configuration.

`/stats`

* Permission : Rôle de l'équipe / Administrateur
* Description : Affiche un embed contenant des analyses en temps réel extraites de votre base de données NoSQL. Inclut des métriques telles que :
  * Le nombre total de tickets historiques.
  * Les tickets actuellement ouverts.
  * Le nombre total de déclenchements automatiques de la FAQ.
  * La note moyenne des avis utilisateurs (étoiles).
