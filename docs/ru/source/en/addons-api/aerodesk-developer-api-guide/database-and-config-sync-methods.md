# Методы синхронизации базы данных и настроек

Управляйте подключением к активной базе данных и синхронизируйте изменения конфигурации в вашей системе мгновенно. Не забудьте сохранить конфигурацию после внесения прямых изменений через API.

- Проверьте активную DB: `getApi().getBotConfig().database.activeDatabase;` _(Returns "MySQL", "SQLite", "MongoDB", и т.д.)_
- Получить БД Хост: `getApi().getBotConfig().database.host;`
- Сохранить изменения конфигурации: `getApi().saveConfig();` _(Проверяет все изменения, сделанные через API, сохраняются в базу данных/YAML)_
- Перезагрузите конфигурацию: `getApi().reloadConfig();` _(Заставить бота получить свежие данные из базы данных)_
