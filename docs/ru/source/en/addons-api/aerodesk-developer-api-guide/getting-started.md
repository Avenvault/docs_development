# Начало работы

Чтобы получить API для бота, вам нужно иметь в своём `pom.xml`

Включить это в ваш проект:

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. lugins.avenvault. om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com. venvault. iscord</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0.</version>      <! - Обновление до последней версии, когда доступно обновление -->
            <scope>предоставлено</scope>
        </dependency>
    </dependencies>
```

Вы можете найти последнюю версию [here](https://maven.plugins.avenvault.com/) под AeroDesk-API
