# Aloittaminen

Saadaksesi API botti sinun täytyy olla sinun `pom.xml` -tilassa

Sisällytä tämä projektiin:

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. lugins.avenvault. om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com. venvault. iscord</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0.</version>      <! - Vaihda viimeisimpään versioon, kun päivitys on saatavilla -->
            <scope></scope>
        </dependency>
    </dependencies>
```

Uusin julkaisu [here](https://maven.plugins.avenvault.com/) on AeroDesk-API
