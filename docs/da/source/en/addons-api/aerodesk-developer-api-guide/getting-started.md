# Kom I Gang

For at få API til den bot, du har brug for at have i din `pom.xml`

Inkludér dette i dit projekt:

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. lugins.avenvault. om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com. venvault. iscord</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0.</version>      <! - Skift til seneste version, når en opdatering er tilgængelig -->
            <scope>leveret</scope>
        </dependency>
    </dependencies>
```

Du kan finde den seneste udgivelse [here](https://maven.plugins.avenvault.com/) under AeroDesk-API
