# 正在开始

为了获取机器人的 API，您需要在 `pom.xml` 中

在您的项目中包含这个内容：

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. lugins.avenvault om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com。 冒险库。</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0。</version>      <！ - 更新可用时更改为最新版本 -->
            <scope>提供的</scope>
        </dependency>
    </dependencies>
```

您可以在 AeroDesk-API 下找到最新版本的 [here](https://maven.plugins.avenvault.com/)
