# Befehle & Berechtigungen

Bedwars Restrictions ist darauf ausgelegt, automatisch im Hintergrund zu laufen, enthält jedoch einige administrative Befehle für die Live-Verwaltung.

| **Befehl**           | **Beschreibung**                                                                                             | **Berechtigung** |
| -------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------- |
| `/bwr help`          | Zeigt das Admin-Hilfemenü an.                                                                                | `bwr.admin`      |
| `/bwr reload`        | Lädt die `config.yml` (Zonen-Koordinaten) neu, ohne den Server neuzustarten.                                 | `bwr.admin`      |
| `/bwr wand`          | Gibt den Zauberstab zur Regionsauswahl.                                                                      | `bwr.admin`      |
| `/bwr set base-name` | Speichert die aktuelle Auswahl in der Konfiguration und blockiert das Platzieren/Abbauen innerhalb der Zone. | `bwr.admin`      |

(Hinweis: Spieler mit Server-OP-Status erben automatisch alle Berechtigungen)
