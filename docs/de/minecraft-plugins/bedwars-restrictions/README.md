# Bedwars Restrictions

## Bedwars Restrictions

Willkommen zur offiziellen Dokumentation für Bedwars Restrictions. Entwickelt für Spigot- und Paper-Server, bietet dieses Premium-Plugin eine leichtgewichtige, hochleistungsfähige Begrenzungskontrolle für Bedwars-Arenen. Verhindere Map-Exploits, Block-Glitching und Bauen außerhalb des Spielfelds – ohne jegliche Auswirkung auf die Serverleistung.
