# AeroDesk

Der hochleistungsfähige, skalierbare Support-Bot für Discord-Communitys

Willkommen zur offiziellen Dokumentation für das Ticket-System. Entwickelt in Java unter Verwendung der leistungsstarken JDA-Bibliothek (Java Discord API), bietet dieser Bot ein nahtloses, hochgradig optimiertes und funktionsreiches Support-Erlebnis für deinen Server. Unterstützt durch eine flexible Key-Value-NoSQL-Architektur (mit Unterstützung für JSON, MongoDB und SQL via Jackson), ist er darauf ausgelegt, von Tag eins an mit deiner Community zu wachsen.
