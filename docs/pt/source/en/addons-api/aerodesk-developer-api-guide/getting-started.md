# Primeiros passos

Para obter a API do bot você precisa ter no seu arquivo `pom.xml`

Inclua isto em seu projeto:

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. lugins.avenvault. om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com. venvault. iscord</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0.</version>      <! - Mudar para a versão mais recente quando uma atualização estiver disponível -->
            <scope>fornecido</scope>
        </dependency>
    </dependencies>
```

Você pode encontrar a última versão [here](https://maven.plugins.avenvault.com/) sob AeroDesk-API
