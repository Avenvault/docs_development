# Kom igång

För att få API:et för roboten måste du ha i din `pom.xml`

Inkludera detta i ditt projekt:

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. lugins.avenvault. om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com. venvault. iscord</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0.</version>      <! - Ändra till senaste versionen när en uppdatering finns tillgänglig -->
            <scope>tillhandahålls</scope>
        </dependency>
    </dependencies>
```

Du hittar den senaste versionen [here](https://maven.plugins.avenvault.com/) under AeroDesk-API
