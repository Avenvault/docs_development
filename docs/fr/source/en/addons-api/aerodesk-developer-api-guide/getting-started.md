# Commencer

Afin d'obtenir l'API pour le bot vous devez avoir dans votre `pom.xml`

Inclure ceci dans votre projet :

```xml
    <repositories>
        <repository>
            <id>avenvault-discord</id>
            <url>https://maven. Lugins.avenvault. om/discord/</url>
        </repository>
    </repositories>
    
    <dependencies>
        <dependency>
            <groupId>com. « venez. » iscord</groupId>
            <artifactId>AeroDesk-API</artifactId>
            <version>1.0.</version>      <! - Changez vers la dernière version lorsqu'une mise à jour est disponible -->
            <scope></scope>
        </dependency>
    </dependencies>
```

Vous pouvez trouver la dernière version [here](https://maven.plugins.avenvault.com/) sous AéroDesk-API
