# Bedwars Restrictions

## Bedwars Restrictions

Bienvenue dans la documentation officielle de Bedwars Restrictions. Conçu pour les serveurs Spigot et Paper, ce plugin premium offre un contrôle des limites léger et performant pour vos arènes Bedwars. Évitez les exploits de carte, les glitches de blocs et la construction hors limites, sans aucun impact sur les performances du serveur.
