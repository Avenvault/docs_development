# AeroDesk

Le bot de support hautement performant et évolutif pour les communautés Discord

Bienvenue dans la documentation officielle du système de tickets. Développé en Java à l'aide de la puissante bibliothèque JDA (Java Discord API), ce bot offre une expérience de support fluide, hautement optimisée et riche en fonctionnalités pour votre serveur. Reposant sur une architecture NoSQL clé-valeur flexible (prenant en charge JSON, MongoDB et SQL via Jackson), il est conçu pour évoluer avec votre communauté dès le premier jour.
