# Методи синхронізації бази даних та конфігурації

Керуйте активним підключенням бази даних та синхронізуйте зміни конфігурації у вашій системі миттєво. Не забудьте зберегти конфігурацію після внесення прямих змін через API.

- Перевірте Активний DB: `getApi().getBotConfig().database.activeDatabase;` _(Повертає "MySQL", "SQLite", "MongoDB", тощо)_
- Отримати вузол бази даних: `getApi().getBotConfig().database.host;`
- Зберегти налаштування конфігурації: `getApi().saveConfig();` _(Включає всі зміни, що виконуються через API, зберігаються в базі даних та YAML)_
- Перезавантажити конфігурацію: `getApi().reloadConfig();` _(примушує бота отримувати свіжі дані з бази даних)_
