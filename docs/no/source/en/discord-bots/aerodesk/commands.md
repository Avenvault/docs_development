# Kommandoer

### 💻 Kommandoer

Boten benytter Discords moderne Slash-kommando-arkitektur for rene, skjulte utførelser.

#### `/ticketpanel`

* Tillatelse: Kun Admin / Eier
* Beskrivelse: Ruller ut den interaktive nedtrekksmenyen i kanalen hvor kommandoen utføres. Brukere samhandler med dette panelet for å åpne tickets basert på kategoriene du har definert i konfigurasjonen.

#### `/stats`

* Tillatelse: Stabsrolle / Admin
* Beskrivelse: Viser en informasjonsboks (embed) med sanntidsanalyse hentet fra din NoSQL-database. Inkluderer metrikker som:
  * Totalt antall historiske tickets.
  * Antall åpne tickets for øyeblikket.
  * Totalt antall automatiserte FAQ-utløsere.
  * Gjennomsnittlig brukervurdering (stjerner).
