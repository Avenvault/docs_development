# Installationsanleitung

Das Einrichten von Bedwars Restrictions auf deinem Netzwerk geht schnell und einfach. Bitte stelle sicher, dass du deinen gekauften Lizenzschlüssel bereithältst, bevor du beginnen kannst.

1. Plugin herunterladen: Lade die neueste Datei `BedwarsRestrictions.jar` von deinem Anbieter herunter.
2. Auf den Server hochladen: Ziehe die `.jar`-Datei per Drag-and-Drop in den Ordner `/plugins/` deines Servers.
3. Erster Start (Dateien generieren): Starte deinen Server oder führe einen Neustart durch. Das Plugin generiert eine Standard-`config.yml` unter `/plugins/BedwarsRestrictions/` und deaktiviert sich danach vorübergehend selbst (das ist normal).
4. Lizenzschlüssel eingeben: Öffne die generierte `config.yml` und füge deinen gekauften Lizenzschlüssel in das Feld `license-key` ein.
5. Abschließender Neustart: Starte deinen Server neu!

> ⚠️ Hinweis: BedwarsRestrictions wird ohne einen gültigen Lizenzschlüssel nicht geladen. Das Neuladen über Plugman oder `/reload` wird für die Erstauthentifizierung nicht unterstützt. Bitte führe einen vollständigen Serverneustart durch.
