# Befehle

### 💻 **Befehle**

Der Bot nutzt Discords moderne Slash-Befehl-Architektur für saubere, übersichtliche Ausführungen.

#### `/ticketpanel`

* Berechtigung: Nur Admin / Owner
* Beschreibung: Sendet das interaktive Dropdown-Menü in den Kanal, in dem der Befehl ausgeführt wird. Nutzer interagieren mit diesem Panel, um ihre Tickets basierend auf den von dir in der Konfiguration definierten Kategorien zu öffnen.

#### `/stats`

* Berechtigung: Team-Rolle / Admin
* Beschreibung: Zeigt ein Embed mit Echtzeit-Analysen an, die aus deiner NoSQL-Datenbank abgerufen werden. Enthält Metriken wie:
  * Gesamtzahl aller bisherigen Tickets.
  * Aktuell offene Tickets.
  * Gesamtzahl automatisierter FAQ-Auslöser.
  * Durchschnittliche Nutzer-Bewertung (Sterne).
